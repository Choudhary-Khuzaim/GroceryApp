# 🛒 GroceryApp

A lightweight, modern, and intuitive iOS application built with **SwiftUI** for seamless online grocery browsing and cart management. 

---

## 📱 Features

* **Item Catalog**: Browse through a curated list of daily essentials (Avocado, Banana, Chicken, Water, etc.).
* **Interactive Shopping Cart**: Add items to your cart, update quantities, and track total costs in real-time.
* **Clean UI & Animations**: Built using native SwiftUI components with smooth grid layouts and dynamic visual feedback.
* **MVVM Architecture**: Clean separation of concerns with clear data modeling for items, cart states, and shops.
